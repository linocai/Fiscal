# v1.5.1 前端还原计划归档摘要

> 原控制面关闭日期：2026-08-22（Asia/Shanghai）

## 原目标

- 以 `Fiscal 前端设计启动/` 为权威，将 macOS 和 iPhone 正式 live root 从通用 SwiftUI 结构切换为 Fiscal 原型方向。
- 保留 typed services、业务模型、认证、金额、时区、离线、幂等、冲突和写入安全边界。
- macOS 建立顶栏、索引、脊柱、检查器；iPhone 建立今日、中央录入、账目三入口。

## 已完成事实

- v1.5.1 正式 root、基础设计令牌、启动门、录入、四报表镜头和七支出口径已接入。
- Review 期间修复了未知写入、持久 outbox、月份驱动、路由、批量选择、分类预览和 Sheet 生命周期等行为问题。
- iOS Simulator 与 macOS App target 曾通过 Debug 编译；macOS universal 包完成 Developer ID 签名与本机换包。
