# v1.5.2 Build 28 · macOS 月份流水范围快修

> 日期：2026-08-23（Asia/Shanghai）  
> 状态：源码与门禁完成；尚未 commit、tag、push、签名、安装或发布

## 1. 用户发现的问题

Build 27 的正式 macOS 界面选择 `2026 年 7 月` 后，月报汇总显示该月存在支出，但账目区显示 `0 项`。同时历史月份中混入 `今天 · 8 月 23 日` 和未来事项。

## 2. 参考权威与根因

`Fiscal 前端设计启动/Design/00-HANDOFF.md` 规定可点击原型是交互权威。`Fiscal 交互原型 macOS.dc.html` 明确定义：

- 初始镜头为 `全部`；
- 镜头列表同时保留独立的 `全部` 与 `未分类`；
- 只有选择 `未分类` 才使用未分类过滤；
- 未来段只在 `全部` 镜头显示。

Build 27 错误地把静态高保真中的“未分类选中状态”当成默认行为：正式根界面删除了 `全部` 镜头、初始查询硬编码为 `uncategorized`，月份切换只改变日期而没有恢复全部流水，且未来/今天段反而挂在未分类镜头下。

## 3. Build 28 修复

- 恢复 `全部` 为正式 macOS 流水页的第一镜头与默认镜头。
- `全部` 查询使用 `classification=all`；`未分类` 保持独立并仅使用 `classification=uncategorized`。
- 首次进入账目页即使用 Asia/Shanghai 当前月起止日，不再发出无月份边界的列表请求。
- 点击月份时清除旧账户范围、旧归档范围和旧镜头，统一回到该月的全部流水。
- 历史月份不显示当前的今天分隔线或未来事项；当前月也只有在 `全部` 镜头显示这些内容。
- `全部`、`未分类`、`归档` 三个真实账目镜头均保留分页能力。
- 版本保持 `1.5.2`，Build 从 `27` 提升到 `28`。

## 4. 防回归证据

新增正式根界面所使用的范围策略测试，并使用“该月有一笔已分类流水、未分类为 0”的真实列表夹具验证：

- `all + 2026-07-01...2026-07-31` 返回该笔流水；
- 切为 `uncategorized` 后返回空列表；
- 月份入口固定恢复 `all`；
- 当前/未来段仅在当前月份的 `all` 镜头可见。
