# Fiscal archive

This directory keeps historical material out of the active product surface while preserving
release evidence and design provenance.

- `audits/` — completed code and frontend audits.
- `design/` — source artwork and the original prototype handoff.
- `plans/` — superseded or long-range planning records.
- `releases/v1.0-v1.3/` — historical contracts, QA results, and screenshots.
- `releases/v1.4.0/` — the v1.4 release manifest and P24–P29 evidence.
- `releases/v1.5.1/` — signed and locally installed v1.5.1 release evidence.
- `releases/v1.5.2/` — v1.5.2 frontend audit remediation, signed artifacts and local-install evidence.

Current engineering rules and product state remain at the repository root in `AGENTS.md` and
`PROJECT_PLAN.md`. Archive documents describe the repository at the time they were written and
must not override the current code or plan.
