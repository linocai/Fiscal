## v2 · 统一品牌色与多账户方案

用户指出：卡片颜色应符合主色调；信用账户也应框入；实际现金账户、信用账户都很多，侧栏不能逐个平铺。第一轮错误地按少量账户设计，并使现金/信用的视觉待遇不一致。

- 默认状态：[fiscal-mac-target-v2.png](fiscal-mac-target-v2.png)。品牌深青的较亮色阶容器，现金与储蓄、信用账户共同位于一张“账户概览”卡片；各组只显示汇总金额、账户数量及“当前余额 / 当前欠款”。常驻侧栏的高度不随账户数量变化。
- 展开状态：[fiscal-mac-accounts-picker-v2.png](fiscal-mac-accounts-picker-v2.png)。点击分组打开侧栏旁的账户选择浮层：搜索、完整可滚动列表，以及到账户页查看全部的入口。现金与信用使用对称交互。点击具体账户进入对应账户上下文；完整管理在账户页进行，不让侧栏承担完整账户表。
- 浮层列表限定最大高度，随可用窗口向上/下避让；键盘搜索/上下选择/回车打开/Escape 关闭属于实施要求。关闭后保持原页面阅读位置，选中账户的范围由实际路由明示，不能静默修改全局汇总口径。
- 示例“8 个现金账户 / 6 个信用账户”及金额仅展示多账户场景，不是真实用户数据。图中的勾选和箭头定位不能替代真实交互状态定义。
- 两图均使用内置 image_gen；完整提示词见 [accounts-v2-prompts.md](accounts-v2-prompts.md)。用户已在后续消息明确认可 v2 样式；现作为 Mac 设计基准，App 未改动。
