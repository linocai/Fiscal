## 当前导航 v2 与页面关系

- 四个固定目的地：总览 / 交易 / 账户 / 分析，与 Mac 主空间对应。一条完整的圆端玻璃胶囊浮在内容之上，四项等宽、图标与文字同时可见。选中态是轻柔的胶囊形透镜与深青图文，不能恢复成四个独立方形按钮。
- 删除 v1 底部右侧黄色方块。“记一笔”必须是底部顺手且文字明确的创建动作，不伪装成第五个 Tab。v2 图曾把它移到右上角，此处已被后续对话纠正；规划采用系统底部附件区域呈现轻量创建动作，按真实设备验证高度、触控区、内容遮挡和辅助功能。具体决定以 `PROJECT_PLAN.md` 为准。
- 技术落点采用 iOS 26 原生 `TabView`。Apple 的 [SwiftUI 新设计演示](https://developer.apple.com/videos/play/wwdc2025/323/) 明确说明 iPhone 的 Tab 栏浮于内容之上，并有滚动收起及附件区域 API。正式导航的材质、选中动画、安全区和适应性由系统承担，勿给系统栏另罩自绘胶囊/边框；不可冒用 search Tab 角色制造创建按钮。是否收起须按财务操作验证，不能仅因 API 存在就启用。
- 数量按已有日常任务设定，不为了凑满导航引入新预算、投资、提醒或其他业务能力。主页面各自保留位置/筛选/选中上下文；分析页本轮只展示固定入口，完整页面尚未出图。
- “记一笔”打开独立创建页，金额优先；输入区下方集中必要字段，数字键盘下方是明确保存动作。输入时没有底部 Tab 栏，关闭后返回原页面；保存后按既有模型刷新事实。
- iOS 账户页以现金/信用分组选择、汇总、搜索及可滚动账户列表处理多账户。截图中的 8/6 是示例数量；完整列表不能靠横向堆银行卡片承载。

## 实施前后需核对的边界

- 生图比例参考为 393pt 宽度下约 357pt × 64pt 的完整胶囊，选中透镜约 80pt × 52pt；这些仅约束生图，不锁定原生栏尺寸。旧 268pt 导航 + 64pt 黄色方块的分栏尺寸已作废。工程布局服从系统原生 TabView、安全区和动态字体，触控区至少 44pt；底部不能压住最后一条流水或 Home Indicator。
- 导航遵循原生 VoiceOver 选中语义；减少动态效果/降低透明度需要高对比实色呈现。iOS 26 的材质只用于导航轻层次，不把内容做成低对比玻璃。
- 图中折线、汇总口径和账户金额需在实现前核对服务来源；无交易、离线、加载失败不能补虚构曲线或零余额。日期/金额/类型/预览失效/待同步/冲突规则保持现有正确性。
- 主导航和交易类型选择是不同层级；类型切换继续走现有模型校验，不按画面简化业务类型。填写标题/备注时切换实际键盘，金额返回数值输入；自绘键盘如采用，仍通过 CNYAmountParser 和辅助功能验证。
- 预览尚未覆盖分析完整页、深色和最大动态字体，这些需在后续设计与正式验证中完成，不宣称整体 iOS 已验收。
