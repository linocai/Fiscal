## R1 · P2 · Mac「查看全部账户」入口没有打开全部账户

- 定位：`App/Sources/FiscalKit/V15/AppShell/V151MacWorkspace.swift:308`；相关调用 `selectAllAccounts()` 在 1480–1494 行。
- 触发：宽侧栏、账户数大于 4，点击“查看全部 N 个账户”；在财务分析或设置与治理页面也可点击。
- 实际：调用只清除账户筛选与选择，重载流水和未来事项；没有切换到时间线，也没有展开 `prefix(4)` 之外的账户。其他页面仍停在原处，时间线侧栏仍只有前四个账户。该新入口无法显露其文案承诺的全部账户。
- 修复方向：让入口显示完整账户选择器；若意图仅为清除流水筛选，则应明确相应文案并返回时间线。
- 回归：使用至少五个账户，分别从时间线、分析和治理触发入口，验证可看到并选择第五个账户及其正确范围。现有 Mac root fixture 只有三个账户，未覆盖此分支。

## R2 · P3 · iOS 有内容的备注无法收起

- 定位：`App/Sources/FiscalKit/V15/Features/Record/V15RecordViews.swift:272`；按钮行为与文案在 279–280 行。
- 触发：打开记一笔，展开备注，输入任意内容，再点“收起备注”。
- 实际：按钮只切换 `showsNote`，输入框与按钮文案却使用 `showsNote || !model.note.isEmpty`。有内容时条件始终成立，输入框继续占位，文案仍为“收起备注”；反复点击也无法折叠。
- 修复方向：将展开状态与有无内容分开，折叠后保留输入内容，并用摘要或标记表达已有备注。
- 回归：填写备注 → 收起 → 展开，确认折叠生效且文字保留；同时验证空备注和下一笔状态。现有录入 UI 测试未操作备注折叠按钮。
