Fiscal Agent 接入说明

这是 Fiscal 给联网 Agent 使用的公开说明页。页面不包含任何密钥、账单或个人数据。

MCP endpoint： https://mcp.fiscal.linotsai.top/mcp

机器配置： /.well-known/fiscal-agent.json

标准使用顺序

  1. Agent 读取本页或 discovery JSON，使用 POST /auth/challenges 创建 session challenge。
  2. Agent 把返回的 approval_url 发给用户；用户打开页面，用 Google Authenticator 输入当前 6 位验证码。
  3. Agent 使用返回的 X-Fiscal-Poll-Token 轮询 challenge，拿到短期 Session token。
  4. Agent 用 Authorization: Session <session_token> 调用 MCP 工具。会话空闲 2 小时失效，最长 8 小时；验证码每 30 秒变化不会中断已建立的会话。
  5. 读取、分析和暂存账单可以直接完成。真正提交到账本前，Agent 为本次请求创建 operation challenge，用户再次输入一次验证码；该写入授权只允许匹配的请求使用一次，有效 30 分钟。

Agent 应遵守的边界

  • 只向用户索取 Google Authenticator 当前验证码，不索取或记录个人 Fiscal API key。
  • 验证码、Session token、poll token 和 operation token 都不得写入日志、账单备注或公开回答。
  • 先导入、校验、展示摘要，再请求用户批准最终写入；不要跳过预览。
  • 个人 Fiscal API key 是人工使用的 break-glass 兜底钥匙，不属于 Agent 自动流程。

如果 Session 过期，重新创建 session challenge 即可；不需要重新配置 Agent。

用户批准页面

打开 TOTP 批准页面。只有持有本页链接并且能提供当前验证码的人才能批准操作。
